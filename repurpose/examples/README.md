# Worked example

Real output from one run of the `repurpose` skill, unedited.

Source: the David Senra x Travis Kalanick interview (https://www.youtube.com/watch?v=QVnU5lGlKE8), a ~17,000-word transcript fetched with the companion `interview-transcript` skill.

| # | File | Asset |
|---|------|-------|

Every quote in the outputs appears verbatim in the source transcript, and each file passed the `humanizer` mannerism checker (no em dashes, no AI vocabulary) before delivery. Quotes are short excerpts used for commentary; the interview belongs to its creators, so watch the full episode at the link above.
