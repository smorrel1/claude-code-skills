# Durable workspace notes (example)

Hand-written, keyed on workspace TITLE, never on number: cmux renumbers on every
reorder. `refresh_registry.py` joins this onto the live tree to produce
`registry.md`, which is generated and gitignored.

Copy this file to `registry-durable.md` and fill it in with your own workspaces.

| Workspace title | Topic | Key contacts | Notes |
|---|---|---|---|
| my ai tools | Tooling, skills, debugging | | Send pipeline and script bugs here, not to the content owner |
| grant applications | Funding bids, budgets, costings | Programme manager, finance lead | Holds the live budget spreadsheet |
| Accountant | Statutory accounts, payroll, VAT | Accountant | Year end in March |
